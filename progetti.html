♦ Monitoraggio Posidonia Oceanica

Metodi: Rilievi GPS, Fotogrammetria, Analisi GIS.

Un'indagine sullo stato di salute delle praterie di Posidonia nel Mediterraneo. Il progetto documenta la densità dei fasci e la regressione dei limiti inferiori a causa dell'antropizzazione.

Cosa ho imparato: organizzare database complessi utilizzando il markup corretto per i dati scientifici. Differenza tra <section> per i siti di campionamento e <article> per i singoli report. Uso di <figure> e <figcaption> per catalogare i campioni fotografici sottomarini.

♦ Analisi Microplastiche Superficiali

Strumenti: Retino Manta, Spettroscopia, Python per l'analisi dati.

Campionamento e classificazione di frammenti plastici inferiori ai 5mm. Studio della correlazione tra correnti marine e accumulo di polimeri sintetici in aree protette.

Cosa ho imparato: strutturare report informativi densi mantenendo la gerarchia visiva. Uso degli id per referenziare i lotti di campionamento. Applicazione del pattern header / main / footer per dividere ipotesi, risultati e conclusioni scientifiche.

♦ Censimento Fauna Ittica (eDNA)

Tecnologie: Sequenziamento DNA ambientale, Monitoraggio acustico passivo.

Identificazione delle specie presenti in un'area marina tramite tracce genetiche nell'acqua. Un approccio non invasivo per monitorare il passaggio di grandi cetacei e squali pelagici.

Cosa ho imparato: presentare dati molecolari in modo leggibile sul web. Stilizzazione consapevole tramite CSS per tabelle di sequenziamento. Gestione di repository Git per condividere script di bioinformatica con commit chiari e documentati.
